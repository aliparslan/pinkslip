# Pinkslip for iOS

The iOS app: Expo and React Native on `@pinkslip/core`. It replaces the
Capacitor shell in `apps/ios` from 1.1.0 on.

- Jobs and Track tabs. You is hidden for now.
- Track shows Saved and Applied, the two stages the backend records.
- The session token lives at the Keychain item the Capacitor app used
  (`modules/session-keychain`), so updating keeps people signed in.
- Universal links and alert URLs use the web's paths; `src/lib/paths.ts`
  maps them to routes.

## Look

Colors, type sizes, radii, and control heights come from the web's
`packages/ui` tokens. After changing `theme.css` or `skin.css`, run
`bun run tokens` here to regenerate `src/theme/tokens.ts`. Type is SF Pro
until the brand faces are licensed for apps.

## Running

- `bun run web` with `EXPO_PUBLIC_DEMO=1` previews the screens with demo jobs.
- `bun run ios` builds to a simulator on a Mac.
- `bun run check` type-checks; `bun run bundle:ios` makes the release bundle.

`ios/` is generated by `bun run prebuild` and committed, because Xcode Cloud
builds from it. After a prebuild, set `MARKETING_VERSION` in the project to
match `version` in `app.json`.

## Xcode Cloud

The workflow builds `ios/Pinkslip.xcworkspace` with the `Pinkslip` scheme.
`ios/ci_scripts/ci_post_clone.sh` installs Node, Bun, and CocoaPods, then the
packages and pods.

## Quarantine

Every component here is new and waits on review. Each mirrors a part of the
web playground so the two read the same.

- `primitives.tsx`: `Txt`, `Icon`, `Badge`, `CompanyMark`, `Separator`. Used
  on every screen.
- `controls.tsx`: `Button`, `Chip`, `SearchField`. Jobs and Track headers,
  filter sheets, and the job page's bottom bar.
- `JobRow.tsx`: the two-line row with peek and a context menu. Jobs and Track.
- `Facts.tsx`: the wrapping place · pay line. Job page.
- `Description.tsx`: renders a posting parsed by `core/job-description`. Job
  page.
- `Empty.tsx`: empty and error states. Jobs and Track.
