# Technical search visibility audit — October 3, 2026

The public site has several concrete crawlability gaps. These do not establish
why Google currently omits a particular query result; that requires Search
Console's URL Inspection and indexing reports for the verified domain.

## Observed before changes

- The homepage's initial HTML is an empty application container with a short
  `Pinkslip` title, without a description or readable product explanation.
- Both `pinkslip.work` and `pinkslip.alip.dev` serve the same application without
  a canonical URL. Server-rendered privacy/support pages also lack canonicals.
- `/robots.txt` and `/sitemap.xml` return the SPA HTML with HTTP 200 rather than
  crawler files.
- Unknown paths also return the app HTML with HTTP 200: potential soft 404s.
- Personal app routes are not useful public search landing pages.

## Small technical changes

- Add descriptive homepage title, description, canonical and social metadata.
- Use `https://pinkslip.work/` as the canonical public domain on both hosts.
- Serve a real robots file and XML sitemap containing the homepage and the
  existing server-rendered privacy/support pages.
- Add `X-Robots-Tag: noindex` to personal app routes and API responses. Crawlers
  can fetch personal route shells to read this directive; login remains the
  protection for private data. The public homepage stays indexable.
- Add canonical URLs to privacy and support pages.

No public landing page or app redesign is included. The initial homepage still
has little readable product content, and arbitrary unknown SPA paths still need
a routing-aware 404 solution. These remain gaps; metadata and a sitemap alone
will not guarantee discoverability or a ranking improvement.

## Owner verification

In Google Search Console, verify the `pinkslip.work` domain property using its
DNS TXT record. Submit `https://pinkslip.work/sitemap.xml`, inspect the homepage,
and read Google's indexing/canonical result and exclusions. Request indexing
once the technical changes are live. Indexing and search placement are decided
by Google and may take time. Do not submit private app routes as landing pages.
